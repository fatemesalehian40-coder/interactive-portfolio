02 / Artist statement & manifesto

The stage is not a screen. Code is a choreographer, and sensors are active scene partners.

Area of inquiry

I explore performance systems in which bodies, sensors, and generative visuals share authorship. Movement does not trigger decoration; it edits space, time, and attention in real time.

03 / Current explorations

Bodies become
live instruments.

Three research directions shape the portfolio. Each is treated as a living system: visual, performative, and responsive to the audience.

01

Computer vision / movement

Embodied Interface

Camera-based motion analysis turns gesture, distance, and rhythm into visual and sonic parameters—without asking the performer to leave the body behind.

  • Hand & pose tracking
  • Spatial gesture scores
  • Real-time feedback
02

Generative projection / performance

Responsive Stage

Projection is treated as stage architecture: elastic, atmospheric, and able to reorganize itself around a live performer.

  • Real-time image systems
  • Projection scenography
  • Performative light
03

Wearable input / live data

Intimate Signal

Breath, orientation, and physiological data become subtle co-performers—felt as tension and texture rather than displayed as statistics.

  • Wearable sensors
  • Data dramaturgy
  • Somatic interaction

04 / Working method

A choreography
for making.

  1. 01

    Listen to the body

    Begin with a physical rule, score, or sensation—not a visual effect.

  2. 02

    Prototype the relation

    Build small live tests that expose the conversation between gesture and system.

  3. 03

    Compose the feedback

    Tune latency, scale, and ambiguity until the response feels performable.

  4. 04

    Return it to the stage

    Let rehearsal—not the interface specification—decide what remains.
